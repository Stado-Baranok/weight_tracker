# Трекер веса (графики)

Многоязычное консольное приложение для отслеживания динамики изменения веса с визуализацией в виде ASCII-графика.  
Позволяет добавлять записи с датой и весом, просматривать историю, строить график изменения веса, рассчитывать статистику (средний, минимальный, максимальный вес, тренд) и экспортировать данные.

## Особенности
- Добавление записей (дата, вес) с автоматической установкой текущей даты.
- Просмотр всех записей в хронологическом порядке.
- Визуализация изменения веса в виде ASCII-графика (столбчатая диаграмма или линейный график).
- Расчёт статистики: минимальный, максимальный, средний вес, общая динамика (тренд).
- Экспорт данных в CSV для анализа в электронных таблицах.
- Хранение данных в локальном JSON-файле.
- Цветной вывод в терминале (где поддерживается).
- Поддержка аргументов командной строки для быстрых операций.

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости.

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama` (опционально).  
   Запуск: `python weight_tracker.py --add 75.5`

2. **JavaScript (Node.js)**  
   Установка: `npm install commander chalk`  
   Запуск: `node weight_tracker.js --add 75.5`

3. **Go**  
   Запуск: `go run weight_tracker.go --add 75.5`

4. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run -- --add 75.5`

5. **Java**  
   Сборка: `javac -cp gson.jar WeightTracker.java`  
   Запуск: `java -cp .;gson.jar WeightTracker --add 75.5`

6. **C# (.NET Core)**  
   Установка: `dotnet add package Newtonsoft.Json`  
   Запуск: `dotnet run -- --add 75.5`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o weight_tracker weight_tracker.cpp -ljsoncpp`  
   Запуск: `./weight_tracker --add 75.5`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc -cp gson.jar WeightTracker.kt`  
   Запуск: `kotlin -cp .;gson.jar WeightTrackerKt --add 75.5`

## Использование

Общие аргументы командной строки:

- `--add <вес>` – добавить запись о весе (сегодняшняя дата).
- `--date <YYYY-MM-DD>` – указать дату для добавления (опционально, вместе с `--add`).
- `--list` – показать все записи.
- `--chart` – показать ASCII-график изменения веса.
- `--stats` – показать статистику.
- `--export <файл>` – экспортировать данные в CSV.
- `--help` – справка.
